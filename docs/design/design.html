Do / Don't

Do keep the accent to one use per screen — one active toggle, one CTA.
Don't let two accent elements compete for the eye on the same screen.
Do mask API keys with a copy/paste affordance.
Don't render a full unmasked key outside the paste moment.
Do use the dashed border only for "drop a skill here."
Don't reuse dashed borders for any other empty state.
