  source currently pauses automatic observation. Completed identical requests at a
  new observable span are distinct; an unobserved identical delete/retype at the same

  interfaces exist, but per-effect executor integration/reconciliation is Tasks 2/3.

  compaction, paused-request resolution, deadline/time ambiguity and retry UX remain
  their assigned tasks. No real source/provider/native data was touched.
